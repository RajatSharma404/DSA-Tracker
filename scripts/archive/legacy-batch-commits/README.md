# Legacy Batch Commit Scripts Archive

This directory contains one-off historical scripts (`commit-batch-*.js`, `commit-10.js`, `commit-next-10.js`, `commit-to-100.js`, `batch-add.js`) previously used for bulk problem seeding and incremental repository commits.

These scripts have been archived as part of senior developer milestone **8.1 Repository Hygiene** and are preserved here for historical reference. Active problem addition and solution synchronization now use:
- `scripts/add-solution.js` (`npm run add:sol`)
- `scripts/sync-solutions.js` (`npm run sync:sol`)
